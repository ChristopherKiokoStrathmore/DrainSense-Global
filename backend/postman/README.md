1. Postman → Import → the collection and one environment.
2. In the environment set `api_token` (a `NGAO_API_TOKENS` value), `ussd_token` (`USSD_SERVICE_TOKEN`),
   and `webhook_secret` if `WEBHOOK_SECRET` is set. `demo_phone` is the presenter phone; `ward_id` the
   walkthrough ward (12 = Moiben in `seed_demo`; use a real ward id with ACT scores on the ADB).
3. Run **0. Demo walkthrough** with the Collection Runner. It resets the presenter phone, registers by USSD,
   scores, drafts and approves an alert, replies in Kiswahili, corrects the report, plans routes,
   confirms the booking, fires both Wasiliana webhooks, runs the Garissa replay and cleans up.
